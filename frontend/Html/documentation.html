SENTINEL DOCUMENTATION

Scan smarter. Fix security risks faster.

Learn how to use Sentinel to scan source code, upload files, review detected secrets, and follow remediation guidance.

GETTING STARTED

Start scanning in
four simple steps.

01

Open the Dashboard

Open the Sentinel dashboard from the main page or use the Dashboard link in the navigation bar.

02

Enter Source Code

Paste source code into the editor or select a supported source-code or text file.

03

Run the Scan

Click Scan Code for pasted content or Scan File to analyze an uploaded file.

04

Review the Results

Check the finding type, line number, severity, entropy, and recommended remediation steps.

DETECTION ENGINE

What Sentinel
currently detects.

⌘

AWS Access Keys

Detects AWS access-key patterns that may have been accidentally included in source code.

◈

GitHub Tokens

Detects common GitHub token formats and marks them as high-risk credentials.

♢

Private Keys

Detects private-key headers such as RSA, EC, and other private-key formats.

⌁

Hardcoded Passwords

Detects password assignments containing quoted values in source code.

UNDERSTANDING RESULTS

How to read a
security finding.

Finding Type

Identifies the kind of possible secret detected, such as an AWS key or hardcoded password.

Line Number

Shows the source-code line where the possible secret was detected.

Severity

Indicates the estimated risk level: Critical, High, Medium, or Low.

Entropy

Shows the randomness of the detected value. Higher entropy may indicate a stronger secret.
